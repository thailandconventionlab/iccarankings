# Thailand Conventions Lab · ICCA Thailand

แดชบอร์ดงานประชุมสมาคมนานาชาติที่ผ่านเกณฑ์ ICCA พ.ศ. 2559–2569 (2016–2026) ใช้สี TMU และวางโลโก้ BALA ก่อน TMU

เว็บไซต์: https://thailandconventionlab.github.io/iccarankings/

## ความสามารถ

- ภาพรวม: เลือกปี กรองภูมิภาค/จำนวนงาน ค้นหาเมือง คลิกแผนที่หรือชื่อเมือง ดูกราฟจำนวนงานและอันดับ
- เปรียบเทียบ: 1–4 เมือง พร้อมตารางค่าและกลุ่มประเทศอ้างอิงปี 2025
- วางแผน: ตั้งเป้าหมายจำนวนงานและระยะเวลา คำนวณงานที่ต้องเพิ่ม/การเติบโตเฉลี่ย ผลเป็นสถานการณ์สมมติ
- ตาราง: รายเมือง/ประเทศรายปี ค้นหา จัดเรียง แหล่งอ้างอิง ดาวน์โหลด CSV และ JSON
- ไทย/อังกฤษ แชร์ตัวกรองผ่าน URL พิมพ์หรือบันทึก PDF ผ่านเบราว์เซอร์ รองรับมือถือและคีย์บอร์ด

## ขอบเขตข้อมูล

ตรวจสอบ **6 กันยายน 2026** ไม่ได้อัปเดตอัตโนมัติ

- ปี 2025: **171 งาน อันดับโลก 24** มี **18 เมืองใน 17 จังหวัด** รวมรายเมือง **170 งาน** ส่วนต่าง 1 งานยังไม่จัดสรรให้เมืองใด
- ปี 2024: 13 เมือง รวม 158 งาน แยกพัทยา 10 งานและชลบุรี 3 งาน
- ปี 2020–2021 ใช้วิธีรายงานต่างจากอันดับปกติ จึงเป็น `null` ปี 2026 รอข้อมูลทั้งปี
- ปี 2016–2019 และ 2022–2023 มีประวัติเฉพาะเมืองหลักตาม TCL.pdf ไม่ใช่รายชื่อทั้งหมด ไม่มีค่าจึงไม่เท่ากับศูนย์
- ปี 2022 รวมงาน hybrid ที่มีผู้เข้าร่วม ณ สถานที่จริง
- ใช้ตัวเลข PDF 2025 เป็นหลัก: สิงคโปร์ระดับประเทศ 157 งาน ระดับเมือง 156 งาน สหราชอาณาจักร 507 งาน
- ภูมิภาคจัดเพื่อการสำรวจในแดชบอร์ด แผนที่ลดรายละเอียดมาจาก draft01 ไม่ใช่แผนที่เขตปกครองทางการ
- ไม่รับรองรายชื่องานตัวอย่างจาก draft01 ว่าผ่าน ICCA หากไม่มีหลักฐานรายงานรองรับ

แหล่งอ้างอิงอยู่ในหน้าวิธีอ่านข้อมูลและ `assets/data.js`: ICCA GlobeWatch 2025 และ TCL.pdf ที่ผู้จัดทำให้, TCEB, TICA และ ICCA Public Abstract แต่ละปี ไม่เผยแพร่ PDF ต้นฉบับทั้งฉบับซ้ำ

## เปิดในเครื่อง

ใช้ Node.js 20 ขึ้นไป ไม่ต้องติดตั้งแพ็กเกจ

```sh
node scripts/serve.cjs
```

เปิด http://127.0.0.1:4173 หรือเปิด `index.html` โดยตรง (การแชร์อาจใช้กล่องคัดลอกสำรองเมื่อเปิดเป็นไฟล์)

## ตรวจสอบและสร้างไฟล์เผยแพร่

```sh
node --test tests/*.test.cjs
node scripts/build.cjs
```

ผลลัพธ์อยู่ใน `dist/` มีเฉพาะไฟล์เว็บและ assets ไม่มี PDF วิจัย ไฟล์ลับ หรือฐานข้อมูล การทดสอบตรวจการคำนวณ ข้อมูล URL และเทมเพลตทั้งสองภาษา ไม่ใช่การทดสอบเบราว์เซอร์จริงหรือภาพหน้าจอ

## GitHub Pages

1. นำไฟล์ขึ้น `main` ของ `thailandconventionlab/iccarankings`
2. **Settings → Pages → Build and deployment → Source: GitHub Actions**
3. `.github/workflows/deploy.yml` ตรวจข้อมูล สร้างเว็บ และเผยแพร่อัตโนมัติ
4. เปิดลิงก์เว็บเมื่อ workflow สำเร็จ

หากเดิมใช้ **Deploy from a branch → main / (root)** เว็บยังเปิดได้ เพราะ index และ assets อยู่ root เช่นเดิม แต่ควรใช้ GitHub Actions เพื่อให้มีการตรวจก่อนเผยแพร่

## อัปเดตปีใหม่

1. เพิ่มแหล่งข้อมูลใน `assets/data.js` ส่วน `sources` พร้อม URL รุ่นรายงานและหน้าเอกสาร
2. แก้ `country[2026]` เป็น `status: "available"` เมื่อมีข้อมูลจริง
3. เติม `cities[].n[2026]`, `rank[2026]`, `source[2026]` เมืองที่ไม่มีข้อมูลคง `null`
4. เพิ่ม `cityCoverage` เมื่อยืนยันรายชื่อครบ ตรวจยอดประเทศ/เมืองและบันทึกส่วนต่างใน `notes`
5. ปรับข้อความปีล่าสุด ป้ายรอข้อมูล ฐานการจำลอง และ tests ให้สอดคล้อง ไม่แก้เพียงตัวเลข
6. ทดสอบและ build ก่อนเผยแพร่

## โครงสร้าง

- `index.html` — จุดเข้าเว็บ
- `assets/styles.css` — หน้าจอ มือถือ และการพิมพ์
- `assets/app.js` — ตัวกรอง กราฟ ตาราง ดาวน์โหลด และแชร์
- `assets/model.js` — กรอง รวมข้อมูล คำนวณ
- `assets/data.js` — ข้อมูลและแหล่งอ้างอิง
- `assets/thailand.js` — GeoJSON จังหวัดจากฉบับร่าง
- `tests/` — การตรวจข้อมูลและเทมเพลต
- `.github/workflows/deploy.yml` — GitHub Pages

ไม่มี JavaScript dependency ภายนอก แบบอักษรโหลดจาก Google Fonts พร้อมตัวสำรอง ไม่มีบัญชีผู้ใช้ analytics หรือการส่งฟอร์มออกจากเครื่อง สถิติ โลโก้ และแผนที่เป็นของเจ้าของต้นฉบับ โปรดอ้างอิง ICCA และแหล่งที่มาเมื่อใช้ข้อมูลต่อ
